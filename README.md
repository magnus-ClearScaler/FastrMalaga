# ClearScaler × Fastr — Paid Growth Proposal

A single-page, on-brand proposal from **ClearScaler** for **Fastr** (fastrrent.com),
covering performance-driven **Meta** and **Google** advertising aimed at high-intent
tourists in Málaga — starting with the cycling cultures of Benelux and the Nordics.

## What's inside
- `index.html` — the full one-page proposal (static, no build step)

## Highlights
- Uses ClearScaler's brand system (colors `#1E5BD6` / `#3DB6F5`, gradient, logo, tagline,
  light/dark theme).
- **Scope:** Meta Ads + Google Ads management (Fastr supplies its own content).
- **Pricing:** €350/mo Meta + €350/mo Google (Robin partner rate, down from €500 each),
  plus €1,000 upfront onboarding.
- **Targeting:** tourists visiting Málaga from Benelux (NL, BE, LU) and the Nordics
  (DK, SE, NO, FI).
- A **reserved "Proven results" section** for Emirates tourist-sector case studies and
  numbers (to be added once provided by Kian).

## Deploy
Static site — deploys to Vercel as-is (no framework, no build).
The root `index.html` is served directly.
